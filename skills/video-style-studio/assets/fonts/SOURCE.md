# Noto Sans

Bundled from the Google Fonts repository on 2026-11-05.

- Typeface: [Noto Sans variable font](https://github.com/google/fonts/tree/main/ofl/notosans).
- License: SIL Open Font License 1.1; complete text and copyright in `OFL.txt`.
- Font bytes are unmodified. The local filename is `NotoSans.ttf`.
- Used as a portable default for captions, including Spanish accents; it does not imitate a private reference typeface.
